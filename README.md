# AxN Design — Магазин современной одежды 👕

**AxN Design** — это современное веб-приложение на **React**, представляющее собой стильный интернет-магазин одежды. Проект демонстрирует работу с состояниями, фильтрацию данных и динамическое управление корзиной.



---

## 🔥 Ключевой функционал

- **Интерактивный каталог**: Просмотр товаров с плавной анимацией при наведении.
- **Умная фильтрация**: Сортировка товаров по категориям (Zip, Hoodie, Jacket) без перезагрузки страницы.
- **Система заказов**: 
    - Добавление в корзину с проверкой на дубликаты.
    - Удаление товаров из списка заказов.
    - Автоматический расчет итоговой суммы в реальном времени.
- **Quick View**: Просмотр полной информации о товаре в модальном окне с эффектом размытия фона (`backdrop-filter`).
- **Responsive Design**: Полная адаптивность под любые разрешения экранов.

---

## 🛠 Стек технологий

- **Library**: React.js (Hooks & Class Components)
- **Icons**: React Icons (FaShoppingBag, FaTrash)
- **Styling**: CSS3 (Flexbox for Layout, Grid for Items, Keyframes for animations)
- **Font**: Montserrat Alternates
